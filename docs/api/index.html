Description

Input for updating an existing stay listing. Replaces all provided fields.

propertyType - PropertyType! Updated property category.

starRating - BigDecimal Updated star rating.

policiesText - String Updated policies text.
importantInformation - String Updated important information.
hostId - Int! Updated host ID.
propertyBrandId - Int Updated property brand ID.
viewIds - [Int!]! Updated list of view type IDs. Default = []
amenityIds - [Int!]! Updated list of amenity IDs. Default = []
accessibilityIds - [Int!]! Updated list of accessibility feature IDs. Default = []
mealPlanIds - [Int!]! Updated list of meal plan IDs. Default = []
paymentTypeIds - [Int!]! Updated list of accepted payment type IDs. Default = []
travelerExperienceIds - [Int!]! Updated list of traveler experience IDs. Default = []
location - LocationInput Updated geographic coordinates. Omit to clear the location.
